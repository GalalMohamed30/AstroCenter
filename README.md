# أسترو سنتر — صفحة الهبوط

صفحة واحدة متجاوبة (ديسكتوب وتابلت وجوال) مكتوبة بـ HTML وCSS وJavaScript بدون أي مكتبات.

## الملفات

```
index.html          محتوى الصفحة كاملاً
css/style.css       التصميم والألوان والتجاوب
js/main.js          القائمة، الحركات، التحقق من النموذج
assets/logo.png     الشعار الأصلي كما هو
assets/logo-600.png نسخة مصغّرة من الشعار للاستخدام في الصفحة
assets/favicon.png  أيقونة المتصفح
```

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد كما هو على أي استضافة.

## قبل النشر

1. **رقم واتساب:** في أول `js/main.js` اكتب الرقم في `whatsappNumber` بالصيغة الدولية بدون + (مثال: `2010XXXXXXXX`). عند إرسال النموذج سيفتح واتساب ببيانات ولي الأمر جاهزة.
2. **روابط التواصل:** في نفس الملف داخل `social`.
3. **عدد الحصص:** في `index.html` ابحث عن `يحدد لاحقاً`.
4. **لوحة متابعة ولي الأمر:** الأرقام الموجودة توضيحية فقط، وعليها شارة «عرض توضيحي».
5. **إجابات الأسئلة:** راجع إجابات نظام الحصص والأجهزة وطريقة الدفع.
